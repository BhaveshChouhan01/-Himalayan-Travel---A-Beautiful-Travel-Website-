# ✈️ Himalayan Travel - A Beautiful Travel Website 🌍

## 🌟 Introduction  
**Himalayan Travel** is a responsive travel website built using **HTML & CSS**, designed to showcase breathtaking destinations, travel guides, and easy booking options.  

## 🚀 Features  
✅ Stunning homepage with high-quality images 📸  
✅ Smooth navigation and interactive UI 🔄  
✅ Destination highlights and travel guides 🏝️  
✅ Contact and subscription form 📧  

## 🛠️ Technologies Used  
- **HTML5** – Structured the web pages  
- **CSS3** – Styled the website with Flexbox & Grid
